# INSTALL.md — установка Биомашины на Android

Полная инструкция по установке, обновлению и откату debug‑APK Биомашины. Production‑релиз через Google Play описан в [ROADMAP.md](./ROADMAP.md).

---

## 1. Первая установка

### 1.1 Скачивание APK
1. Зайди на страницу репозитория: <https://github.com/Manificento/Biomachine>.
2. Перейди во вкладку **Actions** → выбери последний успешный workflow run **Android Build** (зелёная галочка).
   > Для скачивания артефактов GitHub требует залогиненного аккаунта — это политика GitHub, обойти нельзя. Если аккаунта нет, можно [создать бесплатный](https://github.com/signup) или попросить владельца репозитория поделиться файлом напрямую.
3. Прокрути вниз до секции **Artifacts** → нажми `biomachine-debug-apk` → скачается ZIP.
4. Распакуй ZIP — внутри будет файл `app-debug.apk` (≈10–15 МБ).

### 1.2 Разрешение установки из неизвестных источников
Android по умолчанию блокирует APK не из Play Store.

- **Android 8+ (Oreo и выше):**
  1. Открой APK в файловом менеджере (или из браузера).
  2. Появится диалог: *«Это приложение пытается установить APK»* → **Настройки**.
  3. Включи *«Разрешить установку из этого источника»* для приложения, через которое открываешь файл (Chrome / Files / Telegram).
  4. Вернись назад и нажми **Установить**.
- **Android 7 и ниже:** Настройки → Безопасность → включить *«Неизвестные источники»*.

### 1.3 Установка
**Вариант A — через файловый менеджер:** тапни на `app-debug.apk` → **Установить** → **Открыть**.

**Вариант B — через ADB (для разработчиков):**
```bash
# Включи USB-отладку в Настройках для разработчиков
adb devices                          # должен видеть устройство
adb install biomachine-debug.apk     # первая установка
adb install -r biomachine-debug.apk  # переустановка с сохранением данных
```

### 1.4 Первый запуск и разрешения
1. Тап на иконку **Биомашина** на главном экране.
2. Splash‑экран ≈1.5 сек.
3. Онбординг: 3 экрана (приветствие → структура программы → имя/Pre‑Week).
4. На старте приложение запросит:
   - **Уведомления** (Android 13+) — разреши, иначе таймер отдыха в фоне и напоминания не сработают.
   - **Камера** — можно отказать, фото прогресса просто не будут работать; всё остальное продолжит функционировать.
5. После онбординга открывается **Dashboard** с прогрессом 12 недель.

## 2. Обновление до новой версии

> ⚠️ **Перед обновлением сделай экспорт JSON.** Большинство обновлений сохраняют данные в Capacitor Preferences, но это страховка.

1. **Settings (⚙️)** → секция «Данные» → **Export JSON** → файл сохраняется в `Documents/biomachine-export-YYYY-MM-DD.json` или открывается Share‑меню (Telegram, Drive, e‑mail себе).
2. Скачай новый APK по инструкции 1.1.
3. Установи поверх старого:
   ```bash
   adb install -r biomachine-debug.apk    # -r = reinstall, keeps data
   ```
   или через файловый менеджер — Android автоматически предложит «Обновить».
4. Запусти — данные подгрузятся из Preferences.
5. Если данные исчезли (бывает при крупных миграциях схемы): **Settings → Import JSON** → выбери бэкап.

---

## 3. Откат на предыдущую версию

1. Удали текущее приложение: долгий тап на иконку → **Удалить**.
   > Удаление стирает данные Preferences. Восстановление только из JSON‑бэкапа.
2. Скачай предыдущий APK из старого Actions run (вкладка Actions → выбери run по дате/SHA коммита).
3. Установи как при первой установке (раздел 1).
4. После онбординга **Settings → Import JSON** → выбери бэкап.

## 4. Известные ограничения OEM‑прошивок

Многие производители Android (Xiaomi, Huawei, OPPO, Vivo, Samsung) применяют агрессивные алгоритмы экономии батареи, которые мешают локальным уведомлениям и фоновому таймеру.

### Xiaomi / Redmi (MIUI / HyperOS)
- **Настройки → Приложения → Биомашина → Автозапуск** → включить.
- **Настройки → Батарея → Контроль активности приложений → Биомашина → Без ограничений**.
- Полезно: **Настройки → Уведомления → Биомашина → Показывать на экране блокировки**.

### Huawei / Honor (EMUI / HarmonyOS)
- **Настройки → Приложения → Запуск приложений** → переключить Биомашину в режим «Управлять вручную» → разрешить **Автозапуск**, **Косвенный запуск**, **Работу в фоне**.
- **Диспетчер телефона → Защищённые приложения** → добавить Биомашину.

### Samsung (One UI)
- **Настройки → Уход за устройством → Батарея → Ограничения фонового использования** → убедиться, что Биомашины **нет** в «Глубоком сне» и в «Спящих приложениях».
- **Настройки → Приложения → Биомашина → Батарея → Не оптимизировано**.

### OPPO / Realme / OnePlus (ColorOS / OxygenOS 13+)
- **Настройки → Батарея → Использование батареи в фоне → Биомашина → Разрешить**.
- **Настройки → Конфиденциальность → Менеджер запуска → Биомашина → ВКЛ**.

### Vivo (FuntouchOS / OriginOS)
- **i Manager → Управление приложениями → Автозапуск** → включить для Биомашины.

> Если уведомления таймера приходят с задержкой 30+ сек или вообще не приходят — почти всегда дело в этих настройках, а не в багах приложения.

## 5. Диагностика проблем

| Симптом | Что попробовать |
|---|---|
| Приложение крашится при запуске | Settings Android → Приложения → Биомашина → **Память** → **Очистить кэш** (данные сохранятся). Если не помогло — переустанови APK. |
| Уведомления таймера не приходят | См. раздел 4 (OEM‑настройки). Проверь, что разрешение POST_NOTIFICATIONS дано (Android 13+): Настройки → Приложения → Биомашина → Уведомления → ВКЛ. |
| Звук таймера не играет в silent mode | Это специально: Биомашина использует `@capacitor-community/native-audio`, который **обходит mute** для критичных алертов окончания подхода. Если хочется тихо — выключи звук в Settings приложения. |
| Beep/finish глухой или пропадает | Проверь медиа‑громкость (не звонок!) — Capacitor NativeAudio играет на канале `STREAM_MUSIC`. |
| Камера не открывается | Настройки Android → Биомашина → Разрешения → Камера → Разрешить. |
| Экран гаснет во время тренировки | Ожидаемо только в RestTimer и WorkoutScreen. Если гаснет — проверь, что разрешение `WAKE_LOCK` есть (на Android 14+ оно auto‑granted нормально). |
| Потеря данных после обновления | **Settings → Import JSON** с бэкапом из шага 2.1. Если бэкапа нет — данные восстановить нельзя, это debug‑APK без облака. |
| Фото прогресса исчезли | Фото хранятся как webPath в Preferences. После переустановки нужны и Preferences, и оригинальные файлы. На v1.x фото сохранятся только при `adb install -r` без удаления. |
| Build на CI падает | См. раздел [DEV.md → Типичные проблемы](./DEV.md). |

## 6. Полная очистка

Если хочется начать с нуля без удаления приложения:

**Settings → секция «Опасная зона» → Сбросить весь прогресс** (требует двойного подтверждения).

Это очистит Preferences, но не системные разрешения и не запланированные напоминания (их нужно отключить тумблерами в Settings → Уведомления).
